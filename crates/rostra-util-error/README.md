# rostra-util-error

Shared error type aliases and formatting helpers used by Rostra crates.

This is an implementation-support crate, not the usual application integration
point. Applications that use Rostra normally depend on
[`rostra-client`](https://docs.rs/rostra-client).

Source and issue tracking: <https://github.com/dpc/rostra>
