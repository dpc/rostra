# rostra-p2p-api

Shared public protocol constants for Rostra peer-to-peer implementations,
including the Iroh ALPN identifier.

This small crate is useful to interoperating transport implementations. It does
not provide a complete Rostra client; application integrations should normally
use [`rostra-client`](https://docs.rs/rostra-client).

Source and issue tracking: <https://github.com/dpc/rostra>
