# rostra-util

Shared small utility helpers used by Rostra crates.

This is an implementation-support crate. Applications that integrate with the
Rostra network normally depend on [`rostra-client`](https://docs.rs/rostra-client)
instead.

Source and issue tracking: <https://github.com/dpc/rostra>
